# baseball-overlay
スコアoverlay

## 画面

| URL | 画面 | 用途 |
|---|---|---|
| `/overlay.html` | オーバーレイ | OBS のブラウザソースに貼る。`?simple=1` でスコア・BSO・ダイヤモンドだけの簡易版 |
| `/ctrl/` | コントローラー | スマホで1球操作（フル機能） |
| `/roster/` | メンバー管理 | PC。オーダー・交代・アナウンス・広告設定 |
| `/spd/` | 球速入力 | スマホのテンキーで球速・球種 |
| `/simple/` | かんたんスコア | 1人運用の簡易版。スコア・BSO・走者だけを1画面で |

## かんたんスコア（`/simple/`）

名簿もアナウンスも広告もいらない試合用。`/simple/` を開いてチーム名を入れ、
OBS には `/overlay.html?simple=1` を貼るだけで配信できる。

- B・S・O はタップで1つずつ増える。4ボールで押し出し（満塁なら1点）、3ストライクで1アウト、
  3アウトで自動的に攻守交代
- 走者はダイヤモンドの塁をタップ
- 得点は各チームの ＋／− で、今の回のマスに入る
- **イニングスコアのマスをタップすると、その回だけを直せる**（＋／−・空欄に戻す）。
  入れ忘れた回や、入れ間違えた回の修正に使う
- 右上のボタンで **6回制 → 7回制 → 9回制** を切り替え
- 「1手戻す」で直前の操作を取り消せる（60手ぶん）
- 状態は端末に保存されるので、読み込み直しても続きから使える
- 画面は1画面に収まるように、端末の幅に合わせて文字とボタンが拡縮する

コントローラー（`/ctrl/`）と同じ形で状態を配るので、**どちらか一方だけを開く**こと。
両方を同時に開くと、あとから送ったほうでオーバーレイが上書きされる。
行き来は `/ctrl/` の設定にある「かんたんスコアを開く」と、`/simple/` 上部の「本体」で。

ホーム画面から開くとアドレスが見えないので、`/ctrl/` の設定に
**「アプリのアドレス」**（4画面のURL＋コピー）を置いてある。
