# baseball-overlay
スコアoverlay

## 画面

| URL | 画面 | 用途 |
|---|---|---|
| `/overlay.html` | オーバーレイ | OBS のブラウザソースに貼る。`?simple=1` でスコア・BSO・ダイヤモンドだけの簡易版 |
| `/ctrl/` | コントローラー | スマホで1球操作（フル機能） |
| `/roster/` | メンバー管理 | PC。オーダー・交代・アナウンス・広告設定 |
| `/spd/` | 球速入力 | スマホのテンキーで球速・球種 |
| `/simple/` | かんたんスコア | 1人運用の簡易版。スコア・BSO・走者だけを1画面で。**トップ（`/`）を開くとここに来る** |
| `/team/?t=away` `/team/?t=home` | チーム用 | 各チームのスタッフが選手の登録・打順・守備位置を入れ、オーバーレイに選手の名前やスタメンを出す |

## かんたんスコア（`/simple/`）

名簿もアナウンスも広告もいらない試合用。`/simple/` を開いてチーム名を入れ、
OBS には `/overlay.html?simple=1` を貼るだけで配信できる。

- B・S・O はタップで1つずつ増える。4ボールで押し出し（満塁なら1点）、3ストライクで1アウト、
  3アウトで自動的に攻守交代
- B・S・O の右の「戻す」で1つ減らせる
- 走者はダイヤモンドの左（三塁）・まん中（二塁）・右（一塁）をタップ
- 得点は各チームの ＋／− で、今の回のマスに入る
- **イニングスコアのマスをタップすると、その回だけを直せる**（＋／−・空欄に戻す）。
  入れ忘れた回や、入れ間違えた回の修正に使う
- 右上のボタンで **6回制 → 7回制 → 9回制** を切り替え
- **📊 スコア表**（イニングの段の右端）… オーバーレイにイニングスコアを **10秒間だけ** 出す
  （得点が入ったときに押す）。10秒たつか、もう一度押すと引っ込む
- 簡易版のオーバーレイは打者も投手も出さないぶん、**チーム名と得点を通常版より大きく**出す
- 「1手戻す」で直前の操作を取り消せる（60手ぶん）
- 状態は端末に保存されるので、読み込み直しても続きから使える
- 画面は1画面に収まるように、端末の幅に合わせて文字とボタンが拡縮する
- オーバーレイのURLと、チーム用アプリのQRコードは上部の「URL・QR」から
- **試合終了は、何回制の設定から自動で判断する**
  - 最終回の表が終わって後攻がリード → 裏に「×」を付けて試合終了
  - 最終回（延長の回）の裏が終わって点差がある → 試合終了
  - 最終回以降の裏に後攻が勝ち越した → サヨナラで試合終了（その回の得点に x）
  - 最終回（延長の回）の裏が**同点**で終わったら、「延長へ」か「引き分けで終了」を選ぶ
    （大会によって延長にも引き分けにもなるため、自動では決めない。選ぶまでカウントや得点は動かせない）
  - 間違えたときは「終了を取り消す」か「1手戻す」

## チーム用（`/team/`）

各チームのスタッフ（選手の顔を知っている人）に、自分のスマホで使ってもらう画面。
かんたんスコアの「URL・QR」に先攻用・後攻用のQRコードがあるので、それを読んでもらう。

- 選手の登録（背番号・名前・ふりがな）。「まとめて追加」なら1行に1人「背番号 名前」で一気に入る
- 打順の数字を押して、その打順に入る選手を選ぶ（入れ替え・控えとの交代もこれで）
- 守備の欄を押して守備位置を選ぶ（同じ守備位置の選手がいたら入れ替わる）
- 「出す」で、オーバーレイの左下に選手の名前（チーム名・打順・守備位置・背番号・ふりがな）が出る。
  表示時間は右上で 5秒／8秒／15秒／消すまで を選べる
- 「スタメンを画面に出す」で、画面のまん中に9人の打順表を15秒出す
- 登録はサーバーに預かるので、別の端末やオーバーレイを開き直しても消えない
  （サーバーが眠って起き直したときは、スタッフのスマホに残っている登録を送り直す）
- 次の試合で別のチームが使うときは「全部消す」
- チーム名とロゴは、コントローラー側で入れたものが出る

## 押すところの決まり（全画面共通・今後もこれを守る）

大会で「ボタンが小さい」「イニングスコアのボタンを押すつもりでボールカウントを押した」
という声があったので、次の値を最低ラインにする。

| 決まり | 値 | 意味 |
|---|---|---|
| 押すところの大きさ | **縦・横とも 48px 以上** | 指先でも押し間違えにくい大きさ |
| となりの押すところとのすき間 | **8px 以上** | となりを一緒に押さないため |
| 役割のちがうかたまりの間 | **16px 以上** | 例：得点の段と B・S・O の段 |

- 文字の大きさに合わせて縮む単位（em）だけで決めず、この値を下回らないようにする
  （`/simple/` では CSS の `--tap` `--gap` `--sep` に入れてある）
- 押し間違えると困るボタン（得点・カウント・攻守交代など）どうしは、なるべく離して置く
- 絵が小さいもの（ダイヤモンドの塁など）は、絵のまわりまで押せるようにする

コントローラー（`/ctrl/`）と同じ形で状態を配るので、**どちらか一方だけを開く**こと。
両方を同時に開くと、あとから送ったほうでオーバーレイが上書きされる。
行き来は `/ctrl/` の設定にある「かんたんスコアを開く」と、`/simple/` 上部の「本体」で。

ホーム画面から開くとアドレスが見えないので、`/ctrl/` の設定に
**「アプリのアドレス」**（4画面のURL＋コピー）を置いてある。
